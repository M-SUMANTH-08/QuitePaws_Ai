# QuietPaws — UI/UX Design Brief

## Design objective
Make the judge understand the product loop in under 15 seconds without reading documentation.

## Visual language
- Dark, technical, calm.
- Green = healthy/local/success.
- Amber = attention.
- Red = intervention/high-arousal signal.
- Purple = uncertain.
- Blue = active/playful.
- Large telemetry labels.
- Monospace for system telemetry.
- No decorative animations that compete with the demo.

## Information hierarchy
1. Product promise.
2. Target/development hardware distinction.
3. Start Live Detection.
4. Camera + workspace.
5. State + approach + response telemetry.
6. Controlled scenarios.
7. Architecture.
8. Legal/privacy.

## Key screens
### Live demo
- Camera preview.
- Workspace rectangle.
- Meeting badge.
- State pill.
- Vision/audio/approach/response telemetry.
- Session log.

### Post-intervention
Show one concise outcome:
- VERIFIED · MOVED AWAY
- STOPPED · OWNER ALERT

### Architecture
SEE → HEAR → THINK → ACT → VERIFY → INFORM.

## Accessibility
- Keyboard focus styles.
- Buttons use real button elements.
- Video has accessible label.
- Reduced motion supported.
- High contrast text.
- No critical information encoded by color alone.

## Mobile
- Single-column demo layout.
- Large touch targets.
- Controls remain visible below camera.
- No horizontal scrolling.

## CTA
One primary CTA: **Start Live Detection**.
Controlled demo buttons are secondary actions.

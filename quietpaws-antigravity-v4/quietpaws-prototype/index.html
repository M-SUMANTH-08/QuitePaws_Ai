SYSTEM DESIGN

👁️

Vision

COCO-SSD runs locally in the browser and supplies dog bounding boxes and confidence.

🎤

Audio

Browser audio uses spectral heuristics. The native Android target uses YAMNet; the two are intentionally distinguished.

📍

Workspace-aware

Dog presence alone is not the product event. Workspace proximity and approach are part of the intervention decision.

🔊

Owner voice proxy

The phone plays a predefined owner cue first, then waits for observable response.

🔁

Closed loop

If the first cue is not verified, one alternate cue is attempted before stopping.

🔒

Offline-first

Inference and session state are local. Network is not used for the browser inference loop.
